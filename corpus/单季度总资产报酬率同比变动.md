# 单季度总资产报酬率同比变动

基础面因子

## 因子公式

其中， ΔROA\_{q,y} 表示本报告期单季度总资产报酬率的同比变动；ROA\_q 表示本报告期单季度总资产报酬率；ROA\_{q,y-1} 表示上年同期单季度总资产报酬率。

本因子计算的是单季度总资产报酬率（ROA）的同比变动量，反映了公司在总资产盈利能力上的季度同比变化情况。

* $ΔROA\_{q,y}$

  :

  本报告期单季度总资产报酬率的同比变动量。
* $ROA\_q$

  :

  本报告期单季度总资产报酬率，通常计算公式为：单季度净利润 / 单季度平均总资产。该值代表公司在当季利用其总资产创造利润的效率。
* $ROA\_{q,y-1}$

  :

  上年同期单季度总资产报酬率，计算公式与ROA\_q相同，只是采用的是上年同期的数据。用于与本期ROA\_q进行比较，分析盈利能力的同比变化。

## 因子解释

本因子属于盈利能力和成长性分析的范畴。具体来说，单季度总资产报酬率（ROA）衡量了公司利用其所有资产创造利润的效率，是衡量盈利能力的重要指标。而其同比变动（即本因子）则反映了公司盈利能力在季度层面的成长性。正的同比变动表明公司本季度总资产盈利能力较去年同期有所提升，负的同比变动则表明盈利能力下降。该因子有助于识别盈利能力增长迅速或者盈利能力下降的企业。 在量化投资中，该指标可用于构建因子，帮助筛选出盈利能力持续增长的公司。相比于环比变动，同比变动能够有效消除季节性影响，使得对公司盈利能力趋势的分析更加准确。同时，增量指标相比增长率指标，受基数影响较小，更能够反映真实的盈利能力变化。
